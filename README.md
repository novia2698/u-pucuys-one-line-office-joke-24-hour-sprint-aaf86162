One short joke about office life, written as a single line: the office plant has been dead for two years and it still got promoted before me. A tiny stdlib-only Python program copies that line from `ENTRY.txt` to the grader's output file, nothing more.

## Run it

```sh
python3 main.py
```

By default it writes to `/output/entry.txt`; set `MAKEFUN_OUTPUT_DIR` to write somewhere else. The joke is 81 characters on one line, inside the bounty's 200-character limit, and the program refuses to write anything empty, multi-line, or over the limit.
